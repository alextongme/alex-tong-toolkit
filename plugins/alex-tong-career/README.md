# alex-tong-career

Career research skills from [Alex Tong's Toolkit](https://alextong.me/toolkit).

```
/plugin marketplace add alextongme/alex-tong-toolkit
/plugin install alex-tong-career@alex-tong-toolkit
```

## Skills

| Skill | Use it when |
|-------|-------------|
| `company-research` | You're deciding whether to apply, or you have an interview booked. Builds a saved markdown packet covering culture, work-life balance, leadership, recent news, headcount, funding, and competitive position — plus an optional role-specific deep-dive on interview stages, the hiring manager, common questions, comp bands, and prep frameworks. |

## What it is not

Not industry analysis without a target company, not investment due diligence, not product teardowns. It answers *"what is it actually like to work there, and how do I get through the loop."*

## Why this is its own plugin

Job searching is a phase, not a permanent mode. Keeping it separate means you install it while you're looking and remove it when you're not, without disturbing the tooling you use every day. See [`.agents/adr/0001-audience-scoped-plugins.md`](../../.agents/adr/0001-audience-scoped-plugins.md).

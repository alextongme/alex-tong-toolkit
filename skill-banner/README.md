# Skill Banner

**Version 1.0.1** · a Claude Code hook · writes nothing · MIT

Prints one banner the moment a skill starts, whether you typed the slash command or Claude picked the skill on its own. Two hooks, one script, writes nothing.

**How it works, what it touches, and how to tell it's working:** [alextong.me/toolkit/skill-banner](https://alextong.me/toolkit/skill-banner?utm_source=github&utm_medium=bio&utm_campaign=evergreen&utm_content=post-body)

**Install:** the install and update commands live in [The AI Kitchen](https://alextong.me/kitchen), free to join. That's also where I post the changelog and answer questions.

Everything it runs is in this folder, so you can read every line before you install it.
